Requerimientos del Proyecto

Qué debe hacer y cómo debe comportarse el sistema

Requerimientos Funcionales
RF-01
Mostrar catálogo de productos

El sistema debe mostrar los productos disponibles con imagen, nombre, categoría y precio.

RF-02
Agregar productos al carrito

El cliente puede agregar productos al carrito, que acumula la cantidad y muestra el total.

RF-03
Formulario de pedido con validación

El formulario valida nombre, correo, teléfono, producto, cantidad, tipo de entrega y extras.

RF-04
Formulario de contacto

El cliente puede enviar consultas mediante un formulario con nombre, correo, asunto y mensaje.

RF-05
Resumen del pedido

Al enviar el formulario se muestra un resumen con los datos ingresados por el cliente.

RF-06
Navegación entre páginas

El sitio cuenta con navbar que enlaza todas las páginas: Inicio, Nosotros, Contacto, Términos y Requerimientos.

Requerimientos No Funcionales
RNF-01
Diseño responsivo

El sitio debe verse correctamente en dispositivos móviles, tablets y escritorio usando Bootstrap.

RNF-02
Identidad visual

Paleta de colores rosa pastel, tipografía Playfair Display y Lato, estilo coherente en todas las páginas.

RNF-03
Código separado por archivos

HTML, CSS y JavaScript están en archivos separados (index.html, style.css, main.js).
